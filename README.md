# Типография PMG — Официальный портал и CRM-система производства

[![GitHub Pages](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-rose?style=for-the-badge&logo=github)](https://porche12.github.io/pmg-typography-crm/)

## 🌟 Ключевые возможности

### 1. Публичный сайт типографии (в стиле PMG.ru)
- **Интерактивный онлайн-калькулятор полиграфии:**
  - 8 категорий изделий: Визитки, Листовки и флаеры, Буклеты, Наклейки и стикеры, Каталоги и брошюры, Упаковка и коробки, Бумажные пакеты, Календари на 2026–2027 гг.

  - Динамический расчет стоимости с кривой скидок от объема тиража и расчетом себестоимости.
  - Встроенный препресс-загрузчик макетов с drag-and-drop и автоматической проверкой разрешения (300 DPI), цветовой модели (CMYK) и вылетов под обрез (2 мм).

- **Каталог продукции с фильтрацией:**

- **Парк промышленного оборудования:**

  - HP Indigo 7900 Digital Press (цифровой офсет, Израиль)

### 2. Встроенная CRM-система типографии PMG
Переключение в CRM осуществляется по кнопке **«📊 Панель CRM»** в шапке сайта или по ссылке `#crm`.

- **Канбан-доска заказов (Pipeline производства):**
  - 8 производственных этапов:
    1. `📥 Новые заявки` (с сайта и калькулятора)
    2. `🔍 Препресс / Макеты` (проверка файлов, цветопроба)
    3. `⏳ Очередь на печать` (материалы зарезервированы)
    4. `🖨️ В производстве` (печать на офсете / цифре)
    5. `✂️ Постпечать и отделка` (ламинация, тиснение, резка)
    6. `📦 Контроль ОТК и упаковка`
    7. `🚚 Готов к выдаче / В доставке`
    8. `✅ Выполнен и оплачен`
  - Drag-and-drop карточек между колонками с автоматической записью истории изменений.
  - Быстрые фильтры по поиску, срочности (⚡ Срочные тиражи) и категориям.
- **Детальная карточка заказа и технологическая карта:**
  - Редактирование параметров заказа, смена ответственного менеджера и печатной машины.
  - Финансовый блок: цена клиента, себестоимость, маржа и расчет прибыли.
  - Статус оплаты (Оплачен 100% / Ожидает оплаты).
  - Лента внутренних заметок и комментариев цеха.
  - Кнопка **«🖨️ Печать техкарты»** — формирование производственного наряда со штрих-кодом для мастера смены и ОТК.
- **База контрагентов (Клиенты CRM):**
  - Список юридических и физических лиц, контактные данные, ИНН, категория (B2B, HoReCa, Агентство, E-commerce).
  - Скидочные уровни: Базовый (0%), Silver (5%), Gold (10%), VIP (15%).
  - Подсчет общего количества заказов и пожизненной ценности клиента (LTV).
- **Мониторинг оборудования цеха:**
  - Индикаторы загрузки оборудования в процентах (0–100%).
  - Текущий выполняемый тираж, количество тиражей в очереди.
  - Смена статусов: `В работе`, `Готов к запуску`, `На техобслуживании`.
- **Склад бумаги и материалов:**
  - Учет остатков листовой бумаги, пленок, фольги Kurz, переплетного картона.
  - Автоматические предупреждающие бейджи `⚠️ ТРЕБУЕТСЯ ЗАКАЗ` при падении ниже неснижаемого остатка.
  - Быстрое пополнение остатка в 1 клик (+1 000 / +5 000 листов).
- **Сводная аналитика и дашборд:**
  - Общая выручка типографии, чистая маржа, процент маржинальности, средний чек тиража.
  - Распределение тиражей по этапам воронки.
  - Рейтинг топ-5 клиентов по объему оплат.

## 🛠 Архитектура и REST API

- **Backend:** Node.js + Express 5, Multer (обработка файлов), атомарная работа с базой данных `data/db.json`.
- **Frontend:** HTML5, Tailwind CSS, кастомный UI-кит `style.css`, чистый Vanilla JS без тяжелых фреймворков.
- **API Эндпоинты:**
  - `GET /api/orders` — список заказов с фильтрами по этапу, категории, срочности и поисковому запросу.
  - `POST /api/orders` — создание заказа из калькулятора или CRM.
  - `GET /api/orders/:id` — детальные данные заказа.
  - `PATCH /api/orders/:id` — обновление этапа (Канбан), машины, цен и статусов.
  - `POST /api/orders/:id/notes` — добавление заметки в ленту тиража.
  - `POST /api/upload` — загрузка макета с препресс-анализом.
  - `GET /api/clients` / `POST /api/clients` — управление базой контрагентов.
  - `GET /api/equipment` / `PATCH /api/equipment/:id` — мониторинг печатного парка.
  - `GET /api/materials` / `PATCH /api/materials/:id` — управление складом бумаги.
  - `GET /api/analytics` — сводные KPI и статистика.
  - `GET /api/track/:query` — публичный поиск статуса заказа по ID или телефону.
